Token Radar (radar-2): every rankable pre-token protocol in the DefiLlama snapshot, ranked by an implied value computed from TVL, seven-day growth, age with no token and chain count — each with a concrete farm plan, in a sortable and filterable dashboard with a model sandbox that re-ranks the board live.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
